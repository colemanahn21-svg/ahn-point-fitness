# Stretch diagram shot list

**64 unique movements · 88 images total** (movement drills need two frames).

Asset names are derived from the stretch name. Drop an image with the exact name below into `Assets.xcassets` and the player picks it up — no code change. Missing art falls back to the text cue, so a partial set works.

**Frames = 2** means the movement *is* the exercise and one still can't show it. Add a second image with the `-end` suffix; the player cross-fades start → end every two seconds and labels each frame.

**⚠️ = unlikely to exist in a general stretching/yoga pose pack (21 of 64).** These are golf-specific, equipment-specific, or breathing drills. Expect to commission, substitute, or leave them on the text fallback.
